# LyricFlux

> 在 Obsidian 里把「听歌」变成沉浸式体验的插件：笔记内嵌歌词播放器，逐字高亮，侧边栏歌单与状态栏控制；支持 MP3 标签编辑、在线多平台歌词获取与翻译，以及多平台歌曲下载与试听。

---
## 这是什么

LyricFlux 是基于 [obsidian-lyric](https://github.com/eatgrass/obsidian-lyric) 的修改插件，并在此基础上扩展成一套完整的「本地音乐播放 + 标签编辑管理 + 多平台下载与试听」系统。

**歌词播放**
- **侧边栏歌词面板** — 右侧栏实时显示歌词，当前行放大高亮，非当前行缩小淡化
- **逐字高亮（卡拉OK）** — 当前行按字/词变色 + 光晕，支持精确 `<mm:ss.xx>` 增强时间戳
- **双语注释** — `原文 | 译文` 竖线语法，译文显示为灰色小字，不参与逐字高亮
- **两种歌单来源** — 音频文件夹（单MP3/FLAC/M4A/OGG）或 LRC 笔记文件夹，二选一
- **绝对路径支持** — 可引用 vault 外的音频/歌词（Windows 盘符路径）

**歌词获取与翻译**
- **在线歌词多平台** — 编辑标签弹窗按来源搜索网易云 / QQ / 酷狗 / 酷我歌词，候选手动选择
- **歌词在线翻译** — 一键把歌词逐行翻译为 `原文 | 译文` 双语（MyMemory / Google / DeepSeek），进度条 + 预计剩余时间

**歌曲下载与试听**
- **多平台下载** — 网易云 / QQ / 酷狗 / 酷我 实时搜索，下载到音频文件夹并自动内嵌歌词/封面/标题
- **下载前试听** — 结果行「试听」拉取标准档音频直接播放（不写入库），同歌再点命中会话内缓存秒播
- **推荐歌单** — 下载弹窗首屏四源推荐歌单胶囊切换，点歌单逐首下载

**标签管理**
- **MP3 标签编辑** — 在插件内编辑标题 / 艺术家 / 专辑 / 歌词 / 封面，可重命名、删除文件【管理音频文件不需要额外安装 mp3tag】
- **M4A 标签编辑** — M4A 也可编辑标签（标题 / 艺术家 / 专辑 / 歌词 / 封面）；酷我 / QQ 下载的 m4a 会自动内嵌标题 / 歌手 / 专辑

详情见下方「使用方法」与「设置页」。

## 安装

### 方式一：BRAT 安装

1. 在 Obsidian 中安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件
2. 打开 BRAT 设置 → 点击 **Add Beta plugin** → 输入仓库地址：
   ```
   https://github.com/fhb263/obsidian-lyricflux
   ```
3. 安装完成后，在 设置 → 第三方插件 → 启用 **LyricFlux**

### 方式二：手动安装

1. 从本仓库的 [Releases](https://github.com/fhb263/obsidian-lyricflux/releases) 下载最新版本的三个文件：
   - `main.js`
   - `styles.css`
   - `manifest.json`
2. 将这三个文件复制到你的 Vault 目录下：
   ```
   <你的Vault>/.obsidian/plugins/obsidian-lyricflux/
   ```
3. 重启 Obsidian → 设置 → 第三方插件 → 启用 **LyricFlux**

## 使用方法

LyricFlux 提供两种用法，按需选择：

### 方式一：在设置里指定音频文件路径，直接在侧边栏播放

1. 设置 → LyricFlux → 歌单 → 歌单来源 选择 **音频文件路径**
2. 在 **音频文件夹** 填入存放音频的文件夹
3. 点击左侧栏 🎵 打开侧边栏，点底部状态栏的歌曲名弹出歌单，点击任意歌曲立即播放

- 文件夹内的 MP3文件自动进歌单，无需任何笔记
- 音频内嵌了带时间戳的歌词会自动同步显示；没有歌词则只播放，可稍后用「编辑标签」补写
- 适合本地音乐文件多、不想为每首歌写笔记的场景

### 方式二：在设置里指定LRC笔记文件路径，写入 `lrc` 代码块后在侧边栏播放

1. 设置 → LyricFlux → 歌单 → 歌单来源 选择 **LRC笔记路径**
2. 在 **LRC笔记文件夹** 填入（或从下拉选择）存放LRC笔记的文件夹
3. 点击左侧栏 🎵 打开侧边栏，点底部状态栏的歌曲名弹出歌单，点击任意歌曲立即播放

- 在笔记中插入 ` ```lrc ` 代码块，声明音频源并写上歌词，阅读模式就会渲染出「播放器 + 歌词」。歌词与字幕跟随笔记走，适合歌词收藏、外语学习、播客文稿。

**① 半内链 — MP3 文件 + 内嵌时间戳（基于库的相对路径）**

`source` 下方直接写带时间戳的歌词：

````markdown
```lrc
source [[music.mp3]]
[00:01.00] 第一行歌词
[00:03.50] 第二行歌词
[00:06.00] 第三行歌词
```
````

**② 全内链 — MP3 文件 + LRC 文件（基于库的相对路径）**

用 `lyrics` 指令引用 vault 内的 LRC/SRT 文件，歌词无需内嵌：

````markdown
```lrc
source [[海阔天空.mp3]]
lyrics [[海阔天空.lrc]]
```
````

- `source [[音频文件]]` — 指定音频源（支持 Obsidian 内部链接或相对路径）
- `lyrics [[歌词文件]]` — 指定歌词文件（LRC 或 SRT 格式）

**③ 全外联 — 引用 vault 外的绝对路径**

也可以使用盘符绝对路径指向 vault 外的音频和歌词文件：

````markdown
```lrc
source C:\Users\用户名\Downloads\musics\海阔天空.mp3
lyrics C:\Users\用户名\Downloads\lyrics\海阔天空.lrc
```
````

- `source` 和 `lyrics` 均支持直接使用 Windows 绝对路径
- 无需将文件放入 vault，适合管理大量本地音乐文件的用户

**④ 内嵌歌词 — 自动读取音频内嵌的歌词标签**

当 `lrc` 代码块**只有 `source`、没有外链歌词也没有内联歌词**时，插件自动从音频文件读取内嵌歌词并显示（MP3 用 MusicBrainz Picard、foobar2000、Mp3tag 等工具写入 ID3 USLT 帧）：

````markdown
```lrc
source [[海阔天空.mp3]]
```
````

- 自动检测：只要没有 `lyrics [[文件]]` 外链、也没有代码块内联歌词，就尝试读取音频内嵌歌词
- 歌词优先级：`lyrics [[文件]]` 外链歌词 > 代码块内联歌词 > 音频内嵌歌词
- 支持 vault 内文件（内部链接 `[[...]]` 或相对路径）以及 Windows 绝对路径
- 除 MP3 外，FLAC / M4A / OGG 的内嵌歌词同样会被自动读取
- 若音频内没有歌词，则不显示歌词（不影响播放器）
- **注意**：仅当内嵌歌词本身带 `[mm:ss]` 时间戳（真 LRC）时，逐行高亮、滚动、侧边栏同步才生效。若内嵌的是纯文本歌词（无时间戳），仅显示文字，无法同步——需先用工具将带时间戳的 LRC 写入音频。

#### 支持格式

- **LRC** — `[hh:mm:ss.xx] 歌词内容`
- **SRT** — SubRip 字幕格式
- **增强 LRC** — `<mm:ss.xx>` 精确逐字时间标记（见下）

#### 逐字高亮

在 设置 → LyricFlux → 基本设置 → 逐字高亮 中开启。开启后：

- 主编辑区：当前行歌词按字逐个变色 + 光晕效果
- 侧边栏：当前行歌词同步逐字变色
- 按语言智能拆词：中文、韩文、阿拉伯语、印地语（天城文）、泰语、藏语按单字拆分；日文（假名与英数字合并为一组）、英文、俄文、亚美尼亚语、格鲁吉亚语按词组拆分，空格保留
- 播放中切换开关可实时重新渲染

#### 精确逐字时间标记

使用主流「增强 LRC」语法 `<mm:ss.xx>` 标记每个字的起始时间，实现卡拉 OK 级精确逐字高亮。

格式：`<绝对时间>文字`，`<>` 内的 `mm:ss.xx` 是该字在歌曲中的绝对时间。

````markdown
```lrc
source [[music.mp3]]
[00:12.167]<00:12.167>沧<00:13.000>海<00:13.833>一<00:14.667>声<00:15.500>笑
[00:19.582]<00:19.582>浮<00:20.100>沉<00:20.600>随<00:21.100>浪<00:21.600>只<00:22.200>记<00:22.800>今<00:23.400>朝
```
````

- 每个 `<mm:ss.xx>` 后紧跟对应的字/词，时间精确到毫秒
- 未使用 `<>` 标记的行自动回退到均分模式
- 主编辑区和侧边栏均支持精确逐字高亮

#### 双语注释语法

用竖线 `|` 分隔第一语言和第二语言，`|` 右侧内容不参与逐字高亮，显示为灰色小字：

````markdown
```lrc
source [[music.mp3]]
[00:01.00] こんにちは世界 | Hello World
[00:03.50] 今天天气真好 | The weather is nice today
```
````

- 主编辑区：第一语言正常显示，第二语言显示为灰色小字
- 侧边栏：注释紧跟在第一语言文字下方
- 逐字高亮仅对第一语言文字生效
- `|` 两侧都非空才会被识别为双语，歌词中孤立的竖线不会被误判
- `<>` 逐字标记与 `|` 可同时使用，互不冲突

#### 右键菜单

在阅读模式（Reading View）中右键歌词区域：

- **播放 / 暂停**
- **跳转到此时间**
- **编辑源码** — 跳到对应歌词行的 Markdown 源码位置
- **复制时间戳** — 复制当前播放位置的时间戳
- **自动滚动** — 开关随播放滚动
- **逐句模式** — 开关每句播完暂停

## 设置页

 在 Obsidian 的 设置 → 第三方插件 → LyricFlux 打开。
 
### 基本设置

这里控制播放时的通用行为：

- **自动滚动** — 开启后歌词随播放进度滚动，当前行始终居中（默认关）
- **逐句模式** — 每句播完自动暂停，适合跟读练发音（默认关）
- **逐字高亮** — 开启后当前行按字/词逐个变色（卡拉 OK 效果），支持增强 LRC 精确时间（默认关）
- **后台播放** — 关闭时最小化自动暂停；开启后最小化仍继续播放（默认关）

### 歌单

决定侧边栏歌单里的歌曲从哪来，二选一：

- **LRC笔记文件夹** — 存放歌词笔记的文件夹；输入框带刷新按钮和搜索下拉，方便定位
- **音频文件夹** — 存放裸音频（MP3、FLAC/M4A/OGG）的文件夹；也是「下载」功能的下载路径（同下载路径）
- **试听缓存** — 显示「试听」拉取的会话内音频缓存大小（重启 Obsidian 自动清空），一键「清除缓存」按钮释放内存；清除后再次试听会重新拉取

### 下载

把歌曲下载到「音频文件夹」。

- **下载路径复用「音频文件夹」**：下载的 MP3 直接写入歌单音频目录，并自动进歌单
- 入口：歌单弹窗搜索框左侧的「下载」按钮，打开「下载歌曲」弹窗，**搜索框实时搜索下拉**→ 点选下载；下载时显示**进度条**（字节百分比）+ 阶段状态文字
- **四源并行搜索**：**网易云 / QQ 音乐 / 酷狗 / 酷我**（网易云、酷狗、酷我**免登录**；QQ 需在「多平台 Cookie」粘贴 QQ 音乐登录 Cookie）。搜索结果**按平台优先级 → 相似度全局排序**（设置页拖动调整平台顺序），行内展示封面缩略图 + 元数据胶囊（**格式[非 mp3 才标注，如 M4A/FLAC]** / VIP / 时长 / 大小 / 码率）
- **试听**：结果行「▶ 试听」按钮——拉取标准档128kbs音频（**不写入库**）直接播放，可随时停止；再次点击同歌命中**会话内缓存**秒播，不重新拉取
- **多平台 Cookie**：设置页「多平台 Cookie」为**可折叠面板**——每平台一行（头部显示「未配置 / 已配置 N 字符」状态 + 「测试连接」按钮，点击展开/收起 textarea，带清除按钮）；默认收起保护凭证；仅存本地
- **平台勾选开关 + 拖动排序**：每平台行行首勾选控制是否参与搜索（未勾选整行变灰），行首**拖动手柄**可拖动调整搜索优先级
- 局限：QQ 下载依赖 Cookie 有效期；VIP / 区域受限歌曲可能失败

### 翻译

「编辑标签」弹窗的「翻译歌词」按钮把歌词每行翻译为 `原文 | 译文` 双语竖线格式：

- **翻译服务商单选**：**MyMemory**（免 key 国内可达，默认稳定源）/ **Google**（国内可能不可达）/ **DeepSeek**（需 API Key，默认模型 `deepseek-v4-flash`；百度/有道已移除）
  - **DeepSeek**：**单次请求整首翻译**，**可随时取消**（立即中断在途请求）；提示词框灰色小字占位默认词，可自定义；**测试连接**校验 API Key 有效性并显示耗时
  - MyMemory/Google：进度条显示「正在翻译 N/M 行」+ 预计剩余时间，可随时中断
- 翻译结果写入 LRC：`[mm:ss.xx] 原文 | 译文`，竖线语法自动识别为双语注释
- 若只想要译文，可再用「编辑标签」手改

## 侧边栏

点击左侧功能区的 🎵 音乐图标，或 `Ctrl+P` 输入 "Open LyricFlux" 打开。

### 歌词面板

打开LRC歌词笔记/播放内嵌歌词的音频后，歌词自动同步到这里：

- **当前行放大高亮**，其余行缩小淡化，一眼看出播到哪
- **滚动实时跟随**当前行，手动滚动后自动拉回居中
- **点击歌词行**即可跳转播放
- 开启逐字高亮后，当前行同步逐字变色
- 双语歌词的译文显示在原文下方

> 若没有歌词，面板会提示「暂无歌词，请打开包含 lrc 代码块的笔记或编辑音频文件标签以显示歌词。」

### 歌单列表

点击状态栏的歌曲名弹出，是管理歌曲的入口：

- 标题旁显示歌曲总数（筛选时显示「筛选后 / 总数」）
- **搜索** — 按歌名或艺术家过滤
- **类型筛选** — 按 frontmatter `type` 或 MP3 专辑过滤，可与搜索叠加
- **下载** — 搜索框**左侧**的下载按钮，打开「下载歌曲」弹窗：搜索框（歌名/艺术家合并搜索，支持回车）+ 右侧搜索按钮，预填当前播放歌曲名称；无预填时首屏展示**推荐歌单**（网易云/QQ/酷狗/酷我四源胶囊切换）→ 结果列表选一首 → **试听**确认或直接**下载** MP3（四平台，网易云/酷狗/酷我免登录，QQ 需 Cookie；自动内嵌歌词+封面）到 指定音频文件夹
- 点击任意歌曲立即播放，无需额外聚焦
- 鼠标悬停歌曲出现操作按钮：
  - **编辑标签**（仅 MP3）— 修改标题 / 艺术家 / 专辑 / 歌词 / 封面，可重命名文件，或**删除文件**（垃圾桶按钮，二次点击确认；vault 内移入回收站可恢复）
  - **查看标签**（非 MP3）— 只读查看标签与歌词
- 歌单打开时，点状态栏的 📌 可滚动定位到当前播放的歌曲
- 支持从网络获取时间戳歌词并嵌入、获取封面并嵌入（接口偶有风控，可稍后再试）

### 状态栏

侧边栏底部是一条完整播放控制条：

- **🔁 播放模式** — 在 关闭 / 单曲循环 / 顺序播放 / 乱序播放 间循环切换
- **▶ / ⏸ 播放 / 暂停**
- **🔊 音量** — 点击弹出滑杆
- **1x 倍速** — 在 0.5x ~ 2x 间切换
- **📌 定位** — 跳到当前歌曲的歌词笔记；歌单打开时则滚动定位
- **歌曲名** — 点击弹出歌单列表
- **00:00 / 03:49** — 当前播放进度

## 自定义样式

通过 CSS 类名自定义样式。以下为主编辑区、侧边栏与状态栏的常用类：

### 主编辑区

- `.lyrics-line` — 每行歌词容器
- `.lyrics-timestamp` — 时间戳文字
- `.lyrics-text` — 歌词正文容器
- `.lyrics-highlighted` — 当前播放高亮行
- `.lyrics-text.lyrics-karaoke` — 逐字高亮模式
- `.lyrics-word` — 逐字高亮的单个字/词
- `.lyrics-word-active` — 当前已高亮的字/词
- `.lyrics-lang-secondary` — 注释/第二语言文字

### 侧边栏

- `.lyrics-panel-content` — 侧边栏歌词容器
- `.lyrics-panel-line` — 侧边栏每行歌词
- `.lyrics-panel-highlighted` — 侧边栏当前行
- `.lyrics-panel-text` — 侧边栏歌词文字容器
- `.lyrics-panel-annotation` — 侧边栏注释文字
- `.lyrics-panel-word` — 侧边栏逐字高亮的单个字/词
- `.lyrics-panel-word-active` — 侧边栏逐字高亮的当前字

### 侧边栏状态栏

- `.lyrics-statusbar` — 状态栏容器
- `.lyrics-statusbar-btn` — 播放/暂停按钮
- `.lyrics-statusbar-mode-btn` — 单曲循环按钮
- `.lyrics-statusbar-speed-btn` — 倍速按钮
- `.lyrics-volume-popup` — 音量弹窗
- `.lyrics-volume-popup-slider` — 音量滑杆

- **单元测试** — Vitest ^4.1.10
- **标签解析** — node-id3 ^0.2.6 / jsmediatags ^3.9.7

---

## 从源码构建

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（esbuild watch）
npm run build      # 生产构建（tsc + esbuild，产物在项目根目录）
npm run test       # 运行 Vitest 单元测试
```

## 已知问题

> 以下问题暂无修复计划。

| #   | 问题                      | 说明                                                            |
| --- | ----------------------- | ------------------------------------------------------------- |
| 1   | **LRC笔记路径下关闭笔记即暂停**     | 关闭标签页歌曲随之暂停                                                   |
| 2   | **LRC笔记路径下最小化后台播放有限制**  | Obsidian 最小化时无法后台渲染新歌；「后台播放」开启时切歌会瞬间弹出窗口又最小化                  |
| 3   | **LRC笔记路径下切歌覆盖当前歌曲标签页** | 切歌（自动/歌单点击）会覆盖当前播放歌曲所在标签页                                     |
| 4   | **仅 MP3 可编辑，其余只读查看**    | 标签编辑仅 MP3（ID3）；FLAC/M4A/OGG 只读查看（标题/艺术家/专辑/歌词/封面），不可编辑，防止损坏文件 |
| 5   | **标签编辑仅桌面可用**           | 移动端无 Node `fs`，无法读写音频标签，自动使用 frontmatter 元数据显示                |
