# LyricFlux

> 在 Obsidian 笔记中嵌入音频播放器 + 逐行滚动歌词 + 逐字高亮，支持侧边栏同步滚动，支持双语注释。

---

## 这是什么

LyricFlux 是基于 [obsidian-lyrics](https://github.com/eatgrass/obsidian-lyric) 的修改版本，在原版基础上新增：

- **精确逐字高亮** — 播放时按字变色 + 光晕，支持主流增强 LRC 的 `<mm:ss.xx>` 精确逐字时间标记
- **双语注释语法** — `原文 | 译文` 竖线格式，译文不参与逐字高亮，显示为第二语言
- **侧边栏歌词面板** — 右侧栏实时显示歌词，当前行放大高亮，非当前行缩小淡化
- **侧边栏逐字高亮** — 侧边栏当前行同步逐字变色
- **侧边栏歌单列表** — 点击歌曲名显示文件夹内所有歌曲，点击切换播放
- **循环播放 / 倍速 / 音量** — 状态栏提供完整播放控制
- **外链歌词** — 支持 `lyrics [[file.lrc]]` 引用 vault 内或绝对路径的歌词文件
- **内嵌歌词提取** — 代码块只有 `source` 时自动读取 MP3 文件 ID3 标签内嵌的 USLT 歌词，无需单独的 LRC 文件
- **对唱/合唱多行高亮** — 同一时间戳的多行歌词（男声+女声）整组同时高亮，主编辑区与侧边栏同步
- **侧边栏定位按钮** — 一键切换到歌词笔记标签页（已打开则切换、未打开则新开，标签排序不变）
- **中文界面** — 设置页、插件简介全部中文化

## 安装

### 方式一：BRAT 安装

1. 在 Obsidian 中安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件
2. 打开 BRAT 设置 → 点击 **Add Beta plugin** → 输入仓库地址：
   ```
   https://github.com/fhb263/obsidian-lyricflux
   ```
3. 安装完成后，在 设置 → 第三方插件 → 启用 **LyricFlux**

### 方式二：手动安装

1. 从本仓库的 [Releases](https://github.com/fhb263/obsidian-lyricflux/releases) 下载最新版本的三个文件：
   - `main.js`
   - `styles.css`
   - `manifest.json`
2. 将这三个文件复制到你的 Vault 目录下：
   ```
   <你的Vault>/.obsidian/plugins/obsidian-lyricflux/
   ```
3. 重启 Obsidian → 设置 → 第三方插件 → 启用 **LyricFlux**

## 使用方法

### 笔记内四种写法

#### ①半内链 — MP3文件 + 内嵌时间戳（基于库的相对路径）

在笔记中插入 ` ```lrc ` 代码块：

````markdown
```lrc
source [[music.mp3]]
[00:01.00] 第一行歌词
[00:03.50] 第二行歌词
[00:06.00] 第三行歌词
```
````

#### ②全内链 — MP3文件 + LRC文件（基于库的相对路径）

使用 `lyrics` 指令引用 vault 内的 LRC/SRT 文件，无需内嵌歌词：

````markdown
```lrc
source [[海阔天空.mp3]]
lyrics [[海阔天空.lrc]]
```
````

- `source [[音频文件]]` — 指定音频源（支持 Obsidian 内部链接或相对路径）
- `lyrics [[歌词文件]]` — 指定歌词文件（LRC 或 SRT 格式）

#### ③全外联 — MP3文件 + LRC文件（支持引用盘符的绝对路径）

也可以使用盘符的绝对路径指向 vault 外的音频和歌词文件：

````markdown
```lrc
source C:\Users\用户名\Downloads\musics\海阔天空.mp3
lyrics C:\Users\用户名\Downloads\lyrics\海阔天空.lrc
```
````

- `source` 和 `lyrics` 均支持直接使用 Windows 绝对路径
- 无需将文件放入 vault，适合管理大量本地音乐文件的用户

#### ④内嵌歌词 — 自动读取 MP3 内嵌的 ID3 歌词

部分音频文件在 ID3 标签中内嵌了歌词（USLT 帧，用 MusicBrainz Picard、foobar2000、Mp3tag 等工具写入）。无需手动声明，当 `lrc` 代码块**只有 `source`、没有外链歌词也没有内联歌词**时，插件会自动从音频文件读取内嵌歌词并显示：

````markdown
```lrc
source [[海阔天空.mp3]]
```
````

- 自动检测：只要没有 `lyrics [[文件]]` 外链、也没有代码块内联歌词，就会尝试读取音频内嵌歌词
- 歌词优先级：`lyrics [[文件]]` 外链歌词 > 代码块内联歌词 > MP3 内嵌歌词
- 支持 vault 内文件（内部链接 `[[...]]` 或相对路径）以及 Windows 绝对路径
- 若音频内没有歌词，则不显示歌词（不影响播放器）
- **注意**：仅当内嵌歌词本身带 `[mm:ss]` 时间戳（真 LRC）时，逐行高亮、滚动、侧边栏同步才生效。若内嵌的是纯文本歌词（无时间戳），仅显示文字，无法同步——需先用工具（或本仓库提供的脚本）将带时间戳的 LRC 写入 MP3。

### 支持格式

- **LRC** — `[hh:mm:ss.xx] 歌词内容`
- **SRT** — SubRip 字幕格式

### 逐字高亮

在 设置 → LyricFlux → 逐字高亮 中开启。开启后：

- 主编辑区：当前行歌词按字逐个变色 + 光晕效果
- 侧边栏：当前行歌词同步逐字变色
- 支持中文（按单字拆分）、日文（假名与英数字合并为一组）、英文（按空格分词，空格保留）、俄文
- 播放中切换开关可实时重新渲染

### 精确逐字时间标记

使用主流「增强 LRC」语法 `<mm:ss.xx>` 标记每个字的起始时间，实现卡拉OK级精确逐字高亮效果。

格式：`<绝对时间>文字`，`<>` 内的 `mm:ss.xx` 是该字在歌曲中的绝对时间。

````markdown
```lrc
source [[music.mp3]]
[00:12.167]<00:12.167>沧<00:13.000>海<00:13.833>一<00:14.667>声<00:15.500>笑
[00:19.582]<00:19.582>浮<00:20.100>沉<00:20.600>随<00:21.100>浪<00:21.600>只<00:22.200>记<00:22.800>今<00:23.400>朝
```
````

- 每个 `<mm:ss.xx>` 后紧跟对应的字/词，时间精确到毫秒
- 未使用 `<>` 标记的行自动回退到均分模式
- 主编辑区和侧边栏均支持精确逐字高亮

### 双语注释语法

用竖线 `|` 分隔第一语言和第二语言，`|` 右侧内容不参与逐字高亮，显示为灰色小字：

````markdown
```lrc
source [[music.mp3]]
[00:01.00] こんにちは世界 | Hello World
[00:03.50] 今天天气真好 | The weather is nice today
```
````

- 主编辑区：第一语言正常显示，第二语言显示为灰色小字
- 侧边栏：注释紧跟在第一语言文字下方
- 逐字高亮仅对第一语言文字生效
- `|` 两侧都非空才会被识别为双语，歌词中孤立的竖线不会被误判
- `{}` 逐字标记与 `|` 可同时使用，互不冲突

### 侧边栏歌词面板

1. 点击左侧栏的音乐图标，或 `Ctrl+P` 输入 "Open LyricFlux"
2. 打开含 `lrc` 代码块的笔记，歌词自动同步到侧边栏
3. 当前行放大高亮，非当前行缩小淡化
4. 开启逐字高亮后，侧边栏当前行同步逐字变色
5. 点击侧边栏歌词行可跳转播放位置

### 侧边栏歌单列表

1. 在 设置 → LyricFlux → LRC笔记文件夹 中设定包含 LRC 笔记的文件夹路径
2. 点击侧边栏底部状态栏的歌曲名，弹出歌曲列表
3. 支持搜索过滤（按歌曲名或艺术家名）
4. 点击歌曲即可切换播放

### 侧边栏状态栏

底部状态栏提供完整播放控制：

| 按钮 | 功能 |
|------|------|
| 🔁 | 开启/关闭单曲循环 |
| ▶ / ⏸ | 播放/暂停 |
| 🔊 | 点击弹出音量滑杆 |
| 1x | 点击切换播放倍速（0.5x ~ 2x）|
| 📌 | 定位到歌词笔记标签页（已打开则切换、未打开则新开，标签排序不变） |
| 歌曲名 | 点击打开歌单列表 |
| 00:00 / 03:49 | 当前播放进度 |

### 右键菜单

在阅读模式（Reading View）中右键歌词区域：

- 播放 / 暂停
- 跳转到此时间
- 编辑源码
- 复制时间戳
- 自动滚动
- 逐句模式

## 插件设置

| 设置项 | 说明 | 默认 |
|--------|------|------|
| 自动滚动 | 默认关闭，启用后 LRC 笔记页跟随当前歌词行滚动（侧边栏始终滚动，不受此项控制） | 关 |
| 逐句模式 | 默认关闭，启用后每句结束自动暂停（适合跟读/学习） | 关 |
| 逐字高亮 | 默认关闭，启用后显示逐字高亮效果（支持主流 <mm:ss.xx> 逐字时间标记，兼容旧 {秒数} 语法） | 关 |
| LRC笔记文件夹 | 设置 LRC 笔记的文件夹路径（在侧边栏显示歌单列表） | 空 |
